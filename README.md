## Deploy:
download source code of signaling server (1 in call needed) from: 
https://github.com/AndreyKuzmaDev/javaphone-signaling and start.

*make sure your ip is public and other computers could make access to you (e.g. use radmin)*
download source code, open in Apache NetBeans 20+, make sure you have compiler for JavaFX 25, JDK24+ (e.g. openjfx, zulu), download dependencies via maven and launch.

### to connect to your friend: 

go to settings and into url of signaling server paste your friend ip address
then he must be in contacts list.
